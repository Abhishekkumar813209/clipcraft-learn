Box & Floor Puzzles — Tough Set

Banking (SBI PO / RBI Grade B) pattern: box stack, floor–flat, floor + age/salary, month–date scheduling, boxes with weights, aur uncertain-count cases. Har set me Pattern tag → Hint → Step-by-step solution → Final stack → sub-questions. Easy → Hard order.

Golden rules — (1) Stack hamesha neeche se upar number karo (bottom = 1). (2) "X is above Y" floating clue hai — usse cases banao; "immediately above/below" fixed hai. (3) "Only two boxes between A and B" = gap of 3 positions. (4) "As many boxes above X as below Y" — dono taraf count barabar karke position nikalo. (5) Extreme clue (top/bottom, ground floor, topmost floor) hamesha pehle lagao.
