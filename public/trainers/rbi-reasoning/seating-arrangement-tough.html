Seating Arrangement — Tough Set

SBI PO / RBI Grade B level. Linear, parallel rows, circular (inside–outside–mixed), square, rectangle, triangle aur uncertain-number cases. Har set me Pattern tag → Hint (kahan se start karein) → Step-by-step solution → Final arrangement → sub-questions. Easy se Hard order me lagaye gaye hain.

Golden rules — (1) Facing centre → left = clockwise, right = anticlockwise. (2) Facing outside → left = anticlockwise, right = clockwise. (3) Parallel rows me "faces each other" ka matlab dono ki left–right mirror ho jaati hai. (4) Hamesha fixed clue (extreme end, exact opposite, middle seat) se shuru karo, phir floating clue (gaps/only two persons) ke 2–3 cases banao aur negative clue se kaato.
