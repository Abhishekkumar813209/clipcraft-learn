PATTERN 01

Sum diya → 2 barabar vaarshik kist nikalo

Trigger: "₹P ki raashi 2 barabar vaarshik kishton mein chukayi jaani hai, r% compounded annually — pratyek kist kitni?" → r=1/n mano; column banao: left = n(n+1) & n², right = (n+1)² & (n+1)²; Kist = P × (n+1)² / (left ka sum).

Q1: 4620, 10%=1/10 → 100+110=210 | 121 → 4620×121/210 = ₹2662 Q2: 1500, 40%=2/5 → 25+35=60 | 49 → 1500×49/60 = ₹1225
Q9: 6800, 12½%=1/8 → 64+72=136 | 81 → 6800×81/136 = ₹4050

Kist di hui → SUM BORROWED (ulta)

Trigger: "₹x ki do samaan vaarshik kishton mein wapas kar diya, dar r% — udhaar li gayi raashi gyaat karo" → Sum = Kist × (left column sum) / (n+1)².

PATTERN 03

Kist di hui → TOTAL INTEREST (difference trick)

Trigger: "pratyek kist ₹x hai, dar r% compounded annually — kul liya gaya byaj gyaat karo" (ya "kul byaj ka 60%") → Interest = Kist × (right sum − left sum) / (n+1)².

Q4: 6897, 10% → 242−210=32 → 6897×32/121 = ₹1824 Q5: 6534, 10% → 6534×32/121 = ₹1728
Q10: 5547, 7½%=3/40 → 3698−3320=378 → 5547×378/1849 = ₹1134
Q13: 5808, 10% → interest=5808×32/121=1536 → 60% = ≈₹922

PATTERN 05

3 barabar vaarshik kisten → kist ya sum (3-row column)

Trigger: "teen samaan vaarshik kishton mein bhugtan, r% compounded annually" — 2 ki jagah 3 rows: n(n+1)², n²(n+1), n³ | dono taraf (n+1)³; Kist = Sum × (n+1)³ / (teen rows ka sum).

Q14: 32760, 20%=1/5 → 180+150+125=455 | 216 → 32760×216/455 = ₹15,552 Q15: 2196, 25%=1/4 → 100+80+64=244 | 125 → 2196×125/244 = ₹1125
Q16 (ulta): kist 3993, 10% → 3993×3310/1331 = ₹9930
Q17 (H.W): kist 21970, 30% → ₹39,990

PATTERN 06

Kisten BARABAR nahi (alag-alag payment) → sum ya rate (chain method)

Trigger: "pehle saal ke ant mein ₹A aur doosre saal ke ant mein ₹B dekar chuka diya" — kist barabar nahi hai, toh formula chhodo: (P×(1+r) − A)×(1+r) − B = 0 bana ke solve karo.

Q18: A=4000, B=7700, 10% → (11P/10−4000)×11/10=7700 → P=₹10,000 Q22: A=4200, B=4410, 5% → (21P/20−4200)×21/20=4410 → P=₹8000
Q19 (rate poochha): P=12000, A=4800, B=9240 → 12000×11/10−4800=8400 → 8400×11/10=9240 ✓ → r=10%

PATTERN 07

Har saal fixed part-payment → bacha hua balance / antim payment

Trigger: "har saal ke ant mein ₹X part payment karta hai — 3rd saal ke ant mein kitna aur dena hoga / kitna bakaya hai" → step-by-step: balance × (1+r), minus X, repeat.

Q20: 9000, 10%, −3000/yr → 9900−3000=6900 → 7590−3000=4590 → ×11/10 = ₹5049 Q23: 50000, 10%, −15000/yr ×3 → 55000−15000=40000 → 44000−15000=29000 → 31900−15000 = ₹16,900 bakaya
Q21: 4000, 8%, −2000 do saal → 4320−2000=2320 → 2505.6−2000=505.6 → ×27/25 = ₹546.05
