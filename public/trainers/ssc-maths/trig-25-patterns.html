PATTERN 01 · BASE RULE

α + β = 90° ka core set — yahi 90% sawal chalata hai

jodo → 90 mile toh product = 1

Trigger: kisi bhi sawal mein do angle ka jod 90° ho jaaye — turant 1 likh do.

Rules: sinα·secβ=1, cosα·cosecβ=1, tanα·tanβ=1, cotα·cotβ=1 Aur: sinα=cosβ, tanα=cotβ, secα=cosecβ  |  sin10=cos80, sin40=cos50
✓

PATTERN 02 · Q1

Har bracket ka product 1 → sirf gunank (coefficient) jodo

each pair = 1 → sum of numbers

Trigger: "2(sin1°·sec89°) + 3(cos11°·cosec79°) + 5(tan21°·tan69°)" — sab pair complementary, matlab har bracket 1.

Q1: 1+89=90, 11+79=90, 21+69=90 → 2(1)+3(1)+5(1) = 10
✓

PATTERN 03 · Q2, Q3

Lambi tan/cot chain → dono sire se pair banao

bahar se andar pair karo

Trigger: "tan5°·tan25°·tan45°·tan65°·tan85°" jaisi chain — pehla × aakhri, doosra × doosra-aakhri; jo bacha (45°, 60°) uski value daal do.

Q2: (tan5·tan85)(tan25·tan65)·tan45 = 1×1×1 = 1 Q3: (cot13·cot77)(cot27·cot63)·cot60 = 1×1×1/√3 = 1/√3

PATTERN 04 · Q4, Q5, Q6

Fraction sin58°/cos32° → seedha 1 (ratio ko product banao)

a/b = a × (1/b) = a·sec/cosec

Trigger: "sin58/cos32", "cos37/sin53", "cosec80/sec10" — neeche wale ko upar le jaao (1/cos = sec), phir 90 check karo.

Q4: sin58·sec32 + (sin55·sec35)/(tan5·tan45·tan85) = 1 + 1/1 = 2 Q5: cos37·cosec53 − cos47·cosec43 = 1 − 1 = 0 Q6: 1 + 3(cosec80·cos10) − 2(1) = 1+3−2 = 2

PATTERN 05 · Q8

PATTERN 06 · Q7

Numerator chain = 1, denominator mein standard angle value

upar 1 → neeche 30/45/60 values

Trigger: chain upar hai aur neeche sec²60, sin²60, cos60 jaisi standard values — upar 1 maan lo, neeche calculation karo.

Q7: upar = 1; neeche = 2×4(3/4 − 3/2 + 2) = 8 × 5/4 = 10 → 1/10

PATTERN 07 · Q9, Q10

sin(...) = cos(...) → dono angle ka jod = 90 likho

angle₁ + angle₂ = 90

Trigger: "cos2A = sin75°" ya "cos(40+x) = sin30°" — different naam (sin vs cos) ho toh angles ka sum 90 rakhna hai.

Q9: 2A + 75 = 90 → 2A = 15 → A = 7.5° Q10: 40 + x + 30 = 90 → x = 20°
✓

PATTERN 08 · Q11

tan = cot (ya sec = cosec) → wahi 90 wala rule

tanA = cotB ⇒ A+B = 90

Trigger: "tan2θ = cot(θ − 36°)" — co-ratio jodi (tan-cot, sin-cos, sec-cosec) mile toh angles jod ke 90 kar do.

Q11: 2θ + θ − 36 = 90 → 3θ = 126 → θ = 42°
✓

PATTERN 09 · Q13, Q14

Do variable (x aur y) → (x+y) direct nikal aata hai

5(x+y) = 90 → x+y

Trigger: "sin(5x−25°) = cos(5y+25°), (x+y) = ?" — jod karke constants cancel karo, gunank se divide.

Q13: 5x−25+5y+25 = 90 → 5(x+y)=90 → 18° Q14: 5θ−10+5φ+20 = 90 → 5(θ+φ)=80 → 16°
✓

PATTERN 10 · Q12

Pehle θ nikaalo → phir di gayi expression mein daalo

θ find → substitute

Trigger: "cos(2θ+54°) = sinθ, toh 1/(cot5θ + sec(5θ/2)) = ?" — do step ka sawal: angle nikaalo, phir standard values.

Q12: 2θ+54+θ = 90 → θ = 12° → 1/(cot60 + sec30) = 1/(1/√3 + 2/√3) = √3/3
✓

PATTERN 11 · Q15

sec = cosec wala → α nikaal ke teen term ki value

α find → cos+sin+tan

Trigger: "sec(5α−15°) = cosec(15°−2α), toh cosα + sin2α + tan(1.5α) = ?"

Q15: 5α−15+15−2α = 90 → 3α = 90 → α = 30° → cos30+sin60+tan45 = √3/2+√3/2+1 = √3+1

PATTERN 12 · Q16

x nikaalo → square wale terms (2sin², cosec²) mein daalo

x find → square values

Trigger: "sin(20+x)° = cos60°, toh 2sin²(3x+15)° − cosec²(2x+10)° = ?"

Q16: 20+x+60 = 90 → x = 10 → 2sin²45 − cosec²30 = 2(1/2) − 4 = 1 − 4 = −3

PATTERN 13 · Q17

PATTERN 14 · Q18

PATTERN 15 · BASE RULE

α+β = 90° ⇒ sin²α + sin²β = 1 aur cos²α + cos²β = 1

square pair = 1

Trigger: square wale do term jinke angle 90 banate hain — seedha 1. (kyunki sinβ = cosα)

Proof: sin²α + cos²α = 1, aur cosα = sinβ ⇒ sin²α + sin²β = 1 Use: sin²32+sin²58 = 1, cos²15+cos²75 = 1, cos²62+cos²28 = 1

PATTERN 16 · Q19

Q19: (1/1) + (sin²53+sin²37) = 1 + 1 = 2

PATTERN 17 · Q20, Q24, Q28

PATTERN 19 · BASE RULE

sec² − tan² = 1 aur tan² − sec² = −1 (sign hi trick hai)

Set: sec²θ − tan²θ = 1, cosec²θ − cot²θ = 1 Ulta: tan²θ − sec²θ = −1, cot²θ − cosec²θ = −1

PATTERN 20 · Q22

sin(A+B) + sec²−tan²

PATTERN 25 · Q29, Q30, Q31, Q32
