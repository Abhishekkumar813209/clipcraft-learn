PATTERN 01

Ek ratio diya → triplet bana ke baaki sab nikaalo

Trigger: "If tanA = 4/3, 0≤A≤90°, then find sinA" — P/B ya P/H dekh ke turant triplet (3,4,5 / 5,12,13 / 7,24,25 / 9,40,41 / 8,15,17 / 11,60,61) lagao.

Q1: tanA=4/3 → P=4,B=3,H=5 → sinA = 4/5 Q2: sinθ=9/41 → B=40 → cotθ = 40/9
✓

PATTERN 02

Triplet yaad na ho → Pythagoras + (a²−b²) trick

Trigger: "sinθ = 9/41" par triplet yaad nahi — x² = 41²−9² = (41−9)(41+9) = 32×50 = 1600 → x=40. Factor tod ke root lo.

Q2: x²=(41)²−(9)²=32×50=1600 → x=40 Q: H=2, P=√3 → x²=4−3=1 → B=1
✓

PATTERN 03

Ratio se values rakh ke poori expression solve

Trigger: "If tanA = 2/5, then value of (…sin²A…)" — pehle triplet/values nikaalo, phir sidha rakh do; simplify baad mein.

Q3: tanA=2/5 → sinA=2/√29, cosA=5/√29 → sin²A = 4/29 Q9: cotθ=3/5 → sinθ=5/√34, cosθ=3/√34 → expression fit karo
✓

PATTERN 04

Self-made formulas: ratio of two functions = teesra function

Trigger: "secθ/cosecθ", "cosecθ/cotθ", "secθ/tanθ" — ratio dikhte hi ek hi function mein badal do: = tanθ, secθ, cosecθ.

Formula: secθ/cosecθ = tanθ; cosecθ/cotθ = secθ; secθ/tanθ = cosecθ Q19: cosecθ/cotθ = 4/3 → secθ=4/3 → cosθ = 3/4
✓

PATTERN 05

a·sinθ = b·cosθ → seedha tanθ = b/a

Trigger: "5sinθ = 4cosθ" ya "12sinA + 12cosA = 17cosA" — dono side ko cos se divide karo, tan mil jaata hai, phir triplet.

Q6: 5sinθ=4cosθ → tanθ=4/5 → P=4,B=5,H=√41 Q17: 12sinA=5cosA → tanA=5/12 → triplet (5,12,13) → answer nikaal lo
✓

PATTERN 06

sin²θ + cos²θ = 1 → ek ko dusre mein badlo

Trigger: Expression mein sin² aur cos² dono mixed ho — 1−sin²θ = cos²θ lagate hi expression single variable ban jaati hai.

Q19: (4sin²θ−1)/(4sin²θ+5), cosθ=3/4 → sin²θ=1−9/16=7/16 → (7/4−1)/(7/4+5) = 1/9
✓

PATTERN 07

Componendo–Dividendo: (a+b)/(a−b) diya ho

Trigger: "(a+b)/(a−b) = k" ya "(sinθ+cosθ)/cosθ = 23/8" — jodo–ghatao karke a/b nikaalo, phir triplet banao.

Trick: (a+b)/(a−b)=5/1 → a/b = (5+1)/(5−1) = 3/2 Q18: (sinθ+cosθ)/cosθ = 23/8 → tanθ = 15/8 → triplet (8,15,17)
✓

PATTERN 08

sec−tan aur sec+tan ek dusre ke RECIPROCAL

Trigger: "secθ + tanθ = √5 + 2 then secθ − tanθ = ?" — kyunki sec²−tan²=1, dono ka product 1. Jodo → 2secθ, ghatao → 2tanθ.

Q: sec+tan=√5+2 → sec−tan=√5−2 → 2sec=2√5 → secθ = √5 Same rule: cosec+cot aur cosec−cot bhi reciprocal (cosec²−cot²=1)
✓

PATTERN 09

(sec−tan)/(sec+tan) = k → cross-multiply karke sin/cos

Trigger: "(secθ−tanθ)/(secθ+tanθ) = 1/7" ya "(cosecθ+cotθ)/(cosecθ−cotθ) = 7" — cross multiply → 6secθ=8tanθ → sinθ = 3/4.

Q21: 7(sec−tan)=sec+tan → 6sec=8tan → sinθ=3/4 → (cosec+cot²)/(cosec−cot²) = 19/5 Q19: (cosec+cot)/(cosec−cot)=7 → cosθ=3/4
✓

PATTERN 10

sin²θ/(tan²θ − sin²θ) = k → cos²θ nikaal lo

Trigger: "sin²θ/(tan²θ − sin²θ) = 5" — tan²=sin²/cos² rakh ke sin² cancel; seedha cos²θ mil jaata hai.

Q20: 6sin²θ = 5sin²θ/cos²θ → cos²θ=5/6 → (24sin²−15sec²)/(6cosec²−7cot²) = −14
✓

PATTERN 11

(secθ − tanθ)² type: value rakho, square karo

Trigger: "(secβ − tanβ)²" jaise expression — pehle ek ratio se sec aur tan alag nikaalo, phir square. Shortcut: (sec−tan)² = (1−sin)/(1+sin).

Q5: cosβ=√3/2 → sec=2/√3, tan=1/√3 → (2−1)²/3 = 1/3
✓

PATTERN 12

ΔABC, B=90° → A + C = 90° (complementary jodi)

Trigger: "In ΔABC right angled at B, sinA·cosC + cosA·sinC = ?" — ye sin(A+C) = sin90° = 1. Value daalne ki zaroorat hi nahi.

Q22: tanA=1/√3 → sin(A+C)=sin90° = 1 Rule: A+C=90° → sinA=cosC, tanA=cotC
✓

PATTERN 13

Triangle mein side-ratio diya → dono angles ki values

Trigger: "ΔABC, ∠B=90° and AB : BC = 1 : 2. Value of cosA + tanC" — sides likh do, A aur C dono ke liye P/B alag-alag hoti hai.

Q23: tanA=1/2 → sinA(cosC+cosA)/cosC(sinC−sinA) = 3 Q24: AB:BC=1:2 → cosA+tanC = (2+√5)/2√5
✓

PATTERN 14

Do ALAG angles (A aur B) diye → do alag triangles

Trigger: "If sinA = 5/13 and 7cotB = 24, then (secA·cosB)(cosecB·tanA)" — A ka apna triplet (5,12,13), B ka apna (7,24,25). Mix mat karo.

Q25: 13/12 × 24/25 × 25/7 × 5/12 = 65/42
✓

PATTERN 15

Standard values (0°,30°,45°,60°,90°) — direct put

Trigger: Question mein sirf standard angles ho — table se values daal ke calculate. sin: 0, ½, 1/√2, √3/2, 1.

Q: 2cot²30° + 3sec²30° = 2×3 + 3×4/3 = 10 Q58: sin²120°+cos²150°−tan²135° = (3+3−4)/4 = 1/2
✓

PATTERN 16

Comparison (bada/chhota): 1ᶜ = 57.27°

Trigger: "sin 1ᶜ ___ sin 10°" ya "cos37° ___ cos40°" — radian ko degree banao (1ᶜ≈57.27°); sin badhta hai, cos ghatta hai 0–90 mein.

Q: sin1ᶜ = sin57.27° > sin10° → > Q: cos37° > cos40° (cos decreasing)
✓

PATTERN 17

π wali value → pehle degree mein convert karo

Trigger: "Find θ if cosθ = −√3/2" with options 3π/2, 2π/3, 5π/6 — har option ko ×180/π karke degree banao, phir match karo.

Q55: 2π/3=120°, 4π/3=240° → cos240° = −√3/2? nahi; cos150° = −√3/2 → 5π/6 Q61: cosx=−½, π/2<x<π → x = 2π/3 (120°)
✓

PATTERN 18

Quadratic equation diya → roots hi trig values hain

Trigger: "x² − 6x + 9 = 0" jaise equation se θ ki value/ratio nikalti hai — factor karo, root ko sin/tan maan lo.

Q: x²−5x+6=0 → x=2,3; x²−7x+12=0 → x=3,4 → common value se ratio banao Q: 6cotθ + 8√10·cosecθ = 6×⅓ + 8 = 10
✓

PATTERN 19

(90° − θ) → function BADAL jaata hai, sign +

Trigger: "tan(90−θ) = 2/√3", "cot85° + cos75°" — 90−θ dikhte hi sin↔cos, tan↔cot, sec↔cosec; sign hamesha +.

Q51: tan(90−θ)=2/√3 → cotθ=2/√3 → 2√3·tanθ+1 = 4 Q54: cot85°+cos75° = tan5° + sin15°
✓

PATTERN 20

(90−θ) wali poori expression → sab convert karke cancel

Trigger: "cos²(90−θ) − [cos(90−θ)·cosθ/cotθ]" — har term ko θ mein badlo, zyadatar sab cancel hoke 0, 1 ya −1 aata hai.

Q52: sin²θ − sin²θ = 0 Q53: [sin(90−θ)cos(90−θ)cot(90−θ)]/(cos²θ−1) = −1
✓

PATTERN 21

ASTC rule: quadrant se SIGN decide

Trigger: Angle (90+θ), (180−θ), (180+θ), (270±θ), (360−θ) — pehle quadrant pehchano, phir ASTC se +/−.

Rule: I sab+, II sin/cosec+, III tan/cot+, IV cos/sec+ Q56: tan(π+θ) = tan(180+θ) = +tanθ
✓

PATTERN 22

90 ka VISHAM multiple → function change; SAM multiple → same

Trigger: (90+θ), (270−θ) → function badlega (sin→cos). (180±θ), (360−θ) → function wahi rahega. Sign ASTC se.

Q: cos120° = cos(90×1+30) → −sin30° = −½ Q: cos240° = cos(90×2+60) → −cos60° = −½
✓

PATTERN 23

Negative angle: sin(−A) = −sinA, cos(−A) = +cosA

Trigger: "sin(−A) = ?" ya "sin(−405°)" — minus bahar nikaalo (sin, tan, cosec, cot odd hain; cos, sec even).

Q50: sin(−A) = −sinA Q66: sin(−405°) = −sin(90×4+45) = −sin45° = −1/√2
✓

PATTERN 24

Bahut BADA angle → 90 se divide (quotient + remainder)

Trigger: "tan4384° + cot6814°" — angle ko 90×n + r likho; n even/odd se function, ASTC se sign. Bade numbers se darna nahi.

Q68: tan(90×48+64) + cot(90×75+64) = tan64° − tan64° = 0 Q: tan1125° = tan(90×12+45) = tan45° = 1
✓

PATTERN 25

sinC ± sinD → Sum-to-Product formula

Trigger: "sin73° + cos137°" ya "sin70° + sin50°" — pehle sab ko sin mein lao, phir 2sin((C+D)/2)cos((C−D)/2).

Q57: sin73°+cos137° = sin73°−sin47° = 2cos60°·sin13° = sin13° Q: sin70°+sin50° = 2sin60°cos10° = √3·cos10°
