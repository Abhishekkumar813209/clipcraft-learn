PATTERN 01

x aur y diya → Down & Up nikaalo

Trigger: "shaant jal mein naav/tairak ki chaal ... aur dhara ki chaal ... hai, dhara ke anukool/pratikool chaal gyaat karo" — seedha jod-ghatav.

Down = x+y, Up = x−y Q1: x=9, y=5 → Up=4 km/h, Down=14 km/h
Practice: x=9,y=3 → D=12, U=6 · x=20,y=12 → D=32, U=8
✓

PATTERN 02

Down & Up diya → x aur y nikaalo

Trigger: "dhara ki disha mein chaal ... , vipreet disha mein ... — naav aur dhara ki chaal kya hai" — half sum / half difference.

x = (D+U)/2, y = (D−U)/2 Q2: D=32, U=28 → x=30 km/h, y=2 km/h
Practice: D=20,U=12 → x=16,y=4 · D=40,U=30 → x=35,y=5
✓

PATTERN 03

Distance/Time se ek chaal nikaalo → doosri find karo

Trigger: "naav X km, T minute mein dhara ke vipreet tay karti hai, dhara ki chaal ... hai to shaant jal ki chaal?" — pehle speed = D/T (hour mein convert), phir ±y.

Q3: U = 12×60/48 = 15, y=2 → x = 15+2 = 17 km/h Q4: 1 km still = 12 min → x=5; river 13 min → U=60/13 → y = 5 − 60/13 = 5/13 km/h
✓

PATTERN 04

Same distance, Down & Up ka TIME diya → chaal ka ulta ratio

Trigger: "naav ek doori anukool 2 ghante mein, wapas 2½ ghante mein aati hai; dhara ki chaal ... to shaant jal ki chaal?" — Time ratio ulta karo = Speed ratio, phir x=(D+U)/2, y=(D−U)/2 units.

Q5: T → 2 : 5/2 = 4:5 ⇒ S → 5:4 → x:y = 9:1 → y=3 ⇒ x = 9×3 = 27 km/h
✓

PATTERN 05

"Up mein n guna samay lagta hai" → x : y ratio

Trigger: "naav ko dhara ke pratikool jaane mein anukool se n guna samay lagta hai" — T(D:U)=1:n ⇒ S(D:U)=n:1 ⇒ x:y = (n+1):(n−1).

Q8: n=3 → D:U = 3:1 → x:y = 2 : 1 Q9: x=5⅓, n=3 → x:y=2:1 → y=8/3 km/h = 20/27 m/s
Q11: x=18, n=2 → x:y=3:1 → y = 6 km/h
✓

PATTERN 06

x = n×y diya + ek trip ka data → actual chaal

Trigger: "shaant jal mein naav ki chaal dhara ki chaal ka teen guna hai, 48 km pratikool jaane mein 6 ghante" — x=3k, y=k rakh ke Up = 2k = D/T.

Q10: x−y = 48/6 = 8 → 2k=8, k=4 → x = 3×4 = 12 km/h
✓

PATTERN 07

Do alag trips → x (ya y) nikaal ke naya samay/doori

Trigger: "naav 3 km pratikool 1 ghante mein aur 1 km anukool 12 min mein — shaant jal mein 6 km mein kitna samay?" / "paper boat kitni doori bahegi" (paper boat ki chaal = y).

Q12: U=3, D=5 → x=4 → t = 6/4 = 1 h 30 min Q13: x = 2/(15/60) = 8, D = 4/(20/60) = 12 → y = 4 → paper boat 2½ h mein 4×2.5 = 10 km
✓

PATTERN 08

Jaana + Aana kul samay T → 2Dx/(x²−y²) = T

Trigger: "gantavya tak jaane aur wapas aane mein kul T ghante lagte hain" — sabse zyada poocha jaane wala formula. D, x ya y kuch bhi poocha ja sakta hai.

Q14: x=10,y=4,T=5 → 2·D·10/84 = 5 → D = 21 km Q15: x=5,y=3,T=3 → 10D/16 = 3 → D = 4.8 km
Q16: x=15, D=20, T=4 → 600/(225−y²)=4 → y = 5√3
Q18: x=6, y=1.5, T=8/3 → D = 7.5 km
✓

PATTERN 09

x, y, doori diye → kul samay poocha

Trigger: "45 km jaakar wapas aata hai, kul samay?" ya "88 km anukool aur 24 km pratikool mein kul samay?" — alag-alag D/(x+y) + D/(x−y) jod do.

Q17: 45/15 + 45/9 = 3+5 = 8 hours Q20: 88/22 + 24/16 = 4 + 1.5 = 5.5 hours
✓

PATTERN 10

"Utne hi samay mein a km down = b km up" → x : y

Trigger: "wo dhara ke saath 4 km utne hi samay mein tay karta hai jitne mein vipreet 3 km" — a/(x+y) = b/(x−y) ⇒ x:y = (a+b):(a−b). Phir 2Dx/(x²−y²)=T se k nikaalo.

Q19: 4:3 → x:y = 7:1 → 2×48×7k/(48k²)=14 → k=1 → y = 1 km/h
✓

PATTERN 11

Same distance: Up ka samay diya → Down ka samay

Trigger: "pratikool nishchit doori 3 ghante mein — anukool utni hi doori mein kitna samay?" — D constant ⇒ t ∝ 1/speed. Speed U:D = 12:16 = 3:4 ⇒ Time = 4:3.

Q21: x=14,y=2 → U=12,D=16 → t = 3 × 3/4 = 9/4 = 2 hr 15 min
✓

PATTERN 12

Ek direction ka data + x diya → doosri direction ka samay

Trigger: "60 km anukool 4 ghante mein, shaant jal chaal 13 km/h — 30 km pratikool kitne samay mein?" — pehle y nikaalo, phir t = D/(x−y).

Q22: x+y = 60/4 = 15 → y=2 → t = 30/11 = 2 8⁄11 hours
✓

PATTERN 13

Do samikaran (a km down + b km up = T) → equations solve

Trigger: "2 ghante mein 15 km anukool aur 8 km pratikool; 2 gh 50 min mein 20 km + 12 km" — v = 1/(x+y), u = 1/(x−y) rakh ke elimination.

Q23: 15v+8u=2 ; 20v+12u=17/6 → v = 1/15 → Downstream speed = 15 km/h
✓

PATTERN 14

"Down chaal, Up se x% adhik" → ratio bana ke solve

Trigger: "anukool chaal, pratikool chaal se 150% adhik hai" — 150% more ⇒ D:U = 250:100 = 5:2. Ab 5k, 2k rakh ke time equation.

Q24: 80/5k + 50/2k = 8.2 → 41/k = 8.2 → k=5 → Down = 5×5 = 25 km/h
✓

PATTERN 15

Dono trips ka D & T → x nikaal ke still water ka samay

Trigger: "55 km pratikool 5 ghante, 75 km anukool 3 ghante — 96 km shaant jal mein kitna samay?" — U aur D nikaalo, x=(D+U)/2, phir t = D/x.

Q25: U=11, D=25 → x=18 → t = 96/18 = 16/3 = 5 hr 20 min
✓

PATTERN 16

Nadi par points (X, P, Q, Y) — doori ke tukde + time ratio

Trigger: "P aur Q rekha XY ko teen barabar bhaagon mein baantte hain, X→Q aur Y→Q ke samay ka anupat 4:5" — har segment ki doori D units maano, direction dekh ke (x+y)/(x−y) lagao.

Q26: (2D/(x+y)) ÷ (D/(x−y)) = 4/5 → 10x−10y = 4x+4y → x:y = 7:3 → Down:current = (7+3):3 = 10 : 3
