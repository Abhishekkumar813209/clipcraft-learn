PATTERN 01

"Buy x get y free" → D% = y/(x+y)

Trigger: "x vastu khareedne par y vastu muft" / "buy 3 get 2 free" — seedha discount % poocha jaaye.

Q1: Buy 7 get 2 free → 2/9×100 = 22²⁄₉% Q2: Buy 3 get 2 free → 2/5×100 = 40%
Q3: 24 bangles par 6 free → 6/30×100 = 20%

PATTERN 03

Buy-Get-Free + upar se aur % off → single D%

Trigger: "buy x get y free + z% additional discount" — equivalent single discount poocha jaaye. Free wale ko fraction bana ke ratio chain karo.

PATTERN 05

Teen successive discounts → single D%

Trigger: "12%, 18% aur 25% ki teen kramik chhut ke barabar single discount?" — (a+b+c) − (ab+bc+ca)/100 + abc/10000.

Q12: 12,18,25 → step-wise: 12+18−2.16 = 24.84; 24.84+25−6.21 = 45.88% Q14: 20,35,10 → 65 − (7+3.5+2) + 0.7 = 53.2%

PATTERN 06

Ratio Method: har discount ko fraction bana ke MP:SP chain

Trigger: discount values aise ho jo aasan fraction bane (10%=1/10, 20%=1/5, 12.5%=1/8, 25%=1/4) — formula ki jagah column chain karo.

Ex: 10%+10% → MP:SP = 10:9 × 10:9 = 100:81 → D = 19/100 = 19% Ex: 20%+20% → 5:4 × 5:4 = 25:16 → 9/25 = 36%

Q55: D=30%, P=20% → 120/70 → markup = 5/7×100 = 71³⁄₇%
