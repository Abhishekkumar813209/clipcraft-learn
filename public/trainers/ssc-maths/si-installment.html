PATTERN 01

"What annual payment will discharge a debt of ₹D in n years at r%"

Trigger: "n saal mein ₹D ke rin/debt ka vaarshik bhugtan (annual payment/installment) kya hoga, r% simple interest" — installment poochha jaaye.

Q1: ₹808, 2yr, 2% → 100+102=202 → 808×100/202 = ₹400 Q2: ₹10750, 4yr, 5% → 100+105+110+115=430 → 10750×100/430 = ₹2500
Q3: ₹1740, 5yr, 8% → 100+108+116+124+132=580 → 1740×100/580 = ₹300
✓

PATTERN 02

Half-yearly / quarterly / 5-monthly kist → r aur t convert karo

Trigger: "kaunsi chhamahi / timahi / 5-maahi kist ₹D ka rin chuka degi, r% per annum" — pehle r aur number-of-installments ko us period mein badlo, phir same 100,100+r,... sum.

Q4: ₹4200, 1yr, 20% half-yearly → r=10%, 2 bar → 100+110=210 → 4200×100/210 = ₹2000 Q5: ₹2120, 1yr, 16% quarterly → r=4%, 4 bar → 100+104+108+112=424 → 2120×100/424 = ₹500
Q6: ₹94500, 1¼yr, 12% 5-maahi → r=5%, 3 bar → 100+105+110=315 → 94500×100/315 = ₹30,000
✓

PATTERN 03

Kisten barabar nahi — ratio mein di hui hain

Trigger: "pehli kist doosri ki 1/3 aur teesri ki 1/4 hai" ya "sabhi kishton ka anupat 1:2:3:5 hai" — har kist ko units maano, use uske baaki-saal ke SI ke saath amount banao, sum = total dena.

Q7: ₹3400, 3 kist 1:3:4, 10% → 100(3y)=130, 300(2y)=360, 400(1y)=440 → 930 units=3400… ratio scale → 400, 1200, 1600 Q8: 1:2:3:5, 1st=₹50, 10% → 50→65, 100→120, 150→165, 250 → total 600 → X=₹600
Q9: ₹25600, 1:2:3, 10% → 100→120, 200→220, 300 → 640 units=25600 → 1 unit=40 → 1st = ₹4000
✓

PATTERN 04

Pehli kisten principal ka fixed hissa → last kist kitni?

Trigger: "pehli 3 kisten mooldhan ki 1/4 hongi aur shesh raashi antim kist mein" — principal ghatate jao, poore saalon ka SI jodo, last kist = bacha principal + total SI.

Q10: ₹480, 6%, 4 kist, har kist=120 principal → balances 480,360,240,120
SI=6/100×(480+360+240+120)=72 → last = 120+72 = ₹192
✓

PATTERN 05

Chhoti sum, monthly barabar kisten → RATE nikalo (series trick)

Trigger: "₹10 udhaar, ₹1 ki 11 maasik kisten" / "₹2070, 10 monthly kist ₹230 each" — rate poochha jaaye. P, A=kist×n, SI=A−P; SI = r/1200 × (P ke ghatate multiples ka sum) = r/1200 × kist × n(n−1)/2.

Q11: P=10, A=11, SI=1 → 1=r/1200×(10+9+…+1)=r×55/1200 → r = 21 9/11 % Q12: P=19, A=20, SI=1 → r×190/1200=1 → r = 6 6/19 %
Q13: ₹2070, 10 kist ₹230 → unit mein P=9, A=10, SI=1 → r×45/1200=1 → r = 80/3 %
✓

PATTERN 06

Cash price vs down payment + kisten → RATE

Trigger: "vastu ka mulya ₹M, ₹D nagad aur ₹x ki n maasik kisten — vaarshik saadharan byaj dar gyaat karo" → P = M−D, A = n×kist, SI = A−P, phir SI = r/1200 × (P, P−x, P−2x… ka sum).

Q14: 10000−2000=8 (unit), A=9 → SI=1 → r/1200×(8+7+…+1)=1 → 33.33% Q15: 39000−19000=200, A=42×5=210, SI=10 → r/1200×(200+158+116+74+32)=10 → 20 20/29 %
Q16: 9000−2200=34, A=7×5=35, SI=1 → r/1200×(34+27+20+13+6)=1 → 12%
✓

PATTERN 07

Down payment + barabar kisten → KIST ki raashi (I ko variable rakho)

Trigger: "₹M cash ya ₹D down payment ke baad n barabar maasik kisten, r% p.a. — kist gyaat karo" → P = M−D, A = nI, SI = nI−P = r/1200 ×[P + (P−I) + (P−2I) + … ] → I solve.

Q17: 500−150=350, 5 kist, 18% → 5I−350 = 3/200(1750−10I) → 103I=7525 → ₹73.06 Q18: 8000−500=7500, 4 kist, 25% → 4I−7500=25/1200(30000−6I) → 33I=65000 → ≈₹1970
Q19: 30000−9400=20600, 4 kist, 15% → 326I=1730400 → ₹5308
Q20 (H.W): 100000−20800=79200, 4 yearly kist, 25% → ₹21,120
✓

PATTERN 08

Beech-beech mein part payment → RATE nikalo (reducing balance SI)

Trigger: "₹P udhaar liya, x saal baad ₹A diya, phir y saal ke ant mein ₹B dekar sara bakaya khatm — dar gyaat karo" → total SI = (sab payments) − P, aur SI = har balance × uske saalon ka byaj ka sum.

Q21: 7000 (3y) → 3000 diya → 4000 (2y); 4000+1050+400=5450 → r=5% Q22: P=15000, A=6500+13460=19960, SI=4960 = 900r+340r=1240r → r=4%
Q23: 10000; SI=2220 = 20r+21r+9r=50r → r=4.44%
✓

PATTERN 09

Reducing balance, rate diya → ANTIM kist kitni?

Trigger: "r% par udhaar, saal-1 ke baad ₹A, saal-2 ke baad ₹B diya, saal-3 ke baad shesh raashi chukayi — final installment?" → har saal balance ko (1+r) se badhao, payment minus karo, aakhri balance = answer.

Q24: 10000×11/10−3000=8000 → ×11/10−2800=6000 → ×11/10 = ₹6600
(ya seedha: 4200+1000+700+420 = 6320 style se interest jodo — dono raste same)
