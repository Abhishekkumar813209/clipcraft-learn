PATTERN 01

Base Rule: a:b::c:d → ad = bc

Trigger: "are in proportion / समानुपात में हैं" — jahan bhi 4 terms proportion mein ho, extremes ka product = means ka product.

a : b :: c : d → a/b = c/d → ad = bc
Missing term nikaalne ka pura chapter isi ek line se chalta hai — bas position dekhni hai.
✓

PATTERN 02

First proportional (3 numbers diye) → x = bc/d

Trigger: "The first proportional of three numbers p, q, r is / तीन संख्याओं का प्रथम अनुपात" — x pehli jagah rakho: x : p :: q : r.

Q1: 6, 12, 24 → x:6::12:24 → x = 6×12/24 = 3 Q(class): 7, 24, 25 → x:7::24:25 → x = 7×24/25 = 168/25
✓

PATTERN 03

Second proportional → x = ad/c

Trigger: "The second proportional of three numbers p, q, r / द्वितीय अनुपात" — x doosri jagah: p : x :: q : r.

Q2: 28, 4, 5 → 28:x::4:5 → x = 28×5/4 = 35 Q(class): 6, 8, 10 → 6:x::8:10 → x = 6×10/8 = 15/2
✓

PATTERN 04

Third proportional (3 numbers) → x = ad/b

Trigger: "The third proportional of three numbers p, q, r / तृतीय अनुपात" — x teesri jagah: p : q :: x : r.

Q3: 2, 3, 15 → 2:3::x:15 → x = 2×15/3 = 10 Q(class): 8, 9, 10 → 8:9::x:10 → x = 80/9 ·  11,12,13 → x = 143/12
✓

PATTERN 05

Fourth proportional → x = bc/a

Trigger: "The fourth proportional to p, q, r / p, q, r का चतुर्थानुपाती" — x aakhri jagah: p : q :: r : x.

Q4: 7,16,21 → 7:16::21:x → x = 16×21/7 = 48 Q5: 5,6,8 → x = 6×8/5 = 9.6  ·  Q6: 5,8,30 → x = 8×30/5 = 48
✓

PATTERN 06

Do alag-alag fourth proportional ka ratio

Trigger: "ratio of the fourth proportional of A,B,C and the fourth proportional of D,E,F" — dono alag nikaalo, phir ratio simplify.

Q7: 2:5::6:x → x=15 ; 6:8::9:y → y=12
x:y = 15:12 = 5 : 4
✓

PATTERN 07

Fractions ka proportional (1/72, 1/168, …)

Trigger: numbers fraction form mein diye ho — same formula lagao, bas division ko reciprocal se multiply karke chalo.

Q8: 1/72 : 1/168 :: 1/150 : x → x = (1/168 × 1/150) ÷ (1/72) = 1/350
✓

PATTERN 08

Sirf 2 numbers diye → beech wala repeat (a:b::b:c)

Trigger: "first proportional of two numbers p and q / दो संख्याओं का प्रथम अनुपात" — middle term repeat hota hai, x = b²/c.

Q9: 3, 5 → x:3::3:5 → x = 9/5 = 1.8 Q(class): 2, 3 → x:2::2:3 → x = 4/3
✓

PATTERN 09

Third proportional (2 numbers) → c = b²/a

Trigger: "third proportional to p and q / p और q का तृतीय अनुपाती" — sirf do number diye ho toh answer = (doosra)² ÷ (pehla).

Q14: 32, 40 → 40²/32 = 50 Q15: 15, 24 → 24²/15 = 576/15 = 38⅖
✓

PATTERN 10

Mean proportion → √(a×c)

Trigger: "mean proportional between p and q / p और q का मध्यानुपाती" — beech wala term: b² = ac.

Q10: 3 aur 27 → √81 = 9 Q11: 144 aur 225 → 12×15 = 180  ·  9 & 16 → 12
✓

PATTERN 11

Decimal mean proportion → phir difference poocha

Trigger: "mean proportional of 1.8 and 3.2 is how much more than 1.8" — pehle √ac nikaalo, uske baad hi subtract karo.

Q(class): M.P = √(1.8×3.2) = √5.76 = 2.4 → 2.4 − 1.8 = 0.6
✓

PATTERN 12

Options mein a, b (variable) ho → value daal ke check

Trigger: question aur options dono algebra mein (a+b, (a+b)/(a−b), √(a+b)) — solve mat karo, chhoti values a=2,b=1 ya a=4,b=1 rakh ke option match karo.

Q12: a=2, b=1 rakho → expression ka maan 3 → option (a+b)/(a−b) = 3 → (c) Q(class): a=4,b=1 → √25 = 5 → jo option 5 de wahi sahi (b=0 daal ke bhi cross-check)
✓

PATTERN 13

Continued proportion → phir 3A+B / 2P+Q type expression

Trigger: "A, 36, 54 are in continued proportion, find 3A+B" — pehle b²=ac se missing terms nikaalo, phir expression ka maan lagao.

Q(TCS): A:36::36:54 → A = 36²/54 = 24 Q(TCS): 8:20::20:P → P = 400/8 = 50, Q = 40 → 2P+Q = 140
✓

PATTERN 14

Term ke andar hi variable ho (2y−1 : 6 :: 6 : 12)

Trigger: proportion ke kisi term mein hi (2y−1), (y+5) jaisa expression diya ho — pehle us term ki value nikaalo, phir chhota equation solve karo.

Q(class): (2y−1):6::6:12 → 2y−1 = 36/12 = 3 → y = 2 Q(CGL 14/07/23): same method se term nikaal ke solve → y = 51
✓

PATTERN 15

Har number mein kya jode/ghatayein ki proportion ban jaye

Trigger: "Which number should be added to/subtracted from each of 4, 10, 12, 24 to make them proportional / प्रत्येक में जोड़ा जाए" — direct formula: x = |(ad−bc) ÷ ((a+d)−(b+c))|.

Q23: 4,10,12,24 → |(96−120)/(28−22)| = 24/6 = 4 (check: 8/14 = 16/28 ✓) Q24: 6,7,15,17 → |(102−105)/(23−22)| = 3
