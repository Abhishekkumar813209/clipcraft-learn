PATTERN 01

Pole / khade aadmi ko cross → D = train ki length

Trigger: "X m lambi train pole/khambhe ya platform par khade vyakti ko t sec mein paar karti hai" — object ki length zero, D = LT hi lagana hai.

Q1: 364 m, 26 sec → S = 364/26 = 14 m/s Q2: 180 m, 54 km/h (=15 m/s) → t = 180/15 = 12 sec
Q3: 63 km/h (=17.5 m/s), 24 sec → L = 17.5×24 = 420 m
✓

PATTERN 02

Platform / Bridge / Tunnel → D = LT + LP

Trigger: "train platform/pul/surang ko t sec mein paar karti hai" — dono lambai jodo, phir speed ya missing length nikaalo.

Q4: (350+1250)/80 = 20 m/s ×18/5 = 72 km/h Q5: (240+360)/30 = 20 m/s = 72 km/h
Q6: 72 km/h = 20 m/s, D=255+745=1000 → t = 50 sec
Q8: 36 km/h=10 m/s, 50 sec → D=500 → pul = 500−348 = 152 m

PATTERN 03

Chalti train, station par KHADI train ko cross

Trigger: "doosri train station par khadi hai" — khadi train sirf ek lambi object hai: D = L₁+L₂, speed sirf chalti train ki.

Q7: D = 108+148 = 256 m, S = 128 km/h = 320/9 m/s
t = 256×18/(128×5) = 7.2 sec
✓

PATTERN 04

Ek train, DO alag platforms → difference trick

Trigger: "400 m platform 50 sec mein aur 600 m platform 60 sec mein paar karti hai" — extra length ÷ extra time = speed, phir length nikaalo.

Q9: Extra 200 m in extra 10 sec → S = 20 m/s = 72 km/h Q9 (length): L+400 = 20×50 = 1000 → L = 600 m
✓

PATTERN 05

Pole/aadmi ka time + platform ka time → L ya platform

Trigger: "man ko 8 sec mein, 264 m platform ko 20 sec mein paar karti hai" — speed same, do equation banao ya extra-time × speed karo.

Q10: L/8 = (L+264)/20 → 20L = 8L+2112 → L = 176 m Q11: S = 750/15 = 50 m/s, extra 10 sec → bridge = 50×10 = 500 m
Q12: 40½ km/h = 11.25 m/s, L = 11.25×24 = 270 → t = 720/11.25 = 64 sec
✓

PATTERN 06

Opposite direction → speeds JODO (S₁+S₂)

Trigger: "do trains vipreet disha mein chal rahi hain, ek doosre ko kitne samay mein paar karengi" — D = L₁+L₂, S = S₁+S₂.

Q13: D=500, S=90 km/h=25 m/s → t = 20 sec Q14: D=500, S=144 km/h=40 m/s → t = 12.5 sec

PATTERN 07

Beech mein GAP diya ho → gap bhi distance mein jodo

Trigger: "do trains 130 m ki doori par hain aur ek doosre ki taraf chalna shuru karti hain" — D = L₁ + gap + L₂.

Q15: D = 230+130+240 = 600, S = 360 km/h = 100 m/s
t = 600/100 = 6 sec

PATTERN 08

Opposite direction mein DOOSRI train ki speed/time nikaalo

Trigger: "ek train ki speed di hai, dono lambai di hai, t sec mein cross karti hain — doosri train ki chaal (ya y sec) batao" — (S₁+x)×5/18 = D/t se ulta solve karo.

Q16: (72+x)×5/18 = 450/9 = 50 → 72+x = 180 → x = 108 km/h Q19: (90+x)×5/18 = 400/10 → 90+x = 144 → x = 54 km/h
Q17: S = 100.8 km/h = 28 m/s, D = 560 → y = 20 sec
✓

PATTERN 09

Dono trains ki speed SAME (ya length same)

Trigger: "dono trains ki chaal barabar hai / dono ki lambai 120 m hai, 8 sec mein cross" — relative speed 2x maan ke ek hi equation.

Q18: 2x×5/18 = 240/8 = 30 → x = 54 km/h Q24: 360 m pole 30 sec → S₁=12 m/s; opposite 15 sec → 720/15=48 → S₂ = 36 m/s
✓

PATTERN 10

Same direction → speeds GHATAO (S₁−S₂)

Trigger: "dono trains ek hi disha mein chal rahi hain / tez train dheemi ko overtake karti hai" — D = L₁+L₂ par S = S₁−S₂.

Q21: A=150 m, B=450 m, relative = 54 km/h = 15 m/s
t = 600/15 = 40 sec
✓

PATTERN 11

Lambai RATIO mein di ho (LA = 4/5 LB)

Trigger: "train A ki lambai train B ki 4/5 hai" — 4k : 5k maan lo, relative speed × time = 9k se k nikaalo.

Q22: LA:LB = 4k:5k, relative 108 km/h = 30 m/s
9k = 30×15 = 450 → k = 50 → LA = 200 m
✓

PATTERN 12

Tunnel ka time + opposite train ka time → 2 equation

Trigger: "train tunnel ko 18 sec mein aur opposite se aa rahi train ko 12 sec mein paar karti hai" — dono se equation banao, L aur S dono unknown.

Q23: 18S = L+240  ·  12(S+15) = L+270
solve → L = 210 m

PATTERN 13

Do train SAME direction → t = (L₁+L₂)/(S₁−S₂)

Trigger: "two trains running in the SAME direction... in how much time will they completely cross each other" — dono lambai jodo, speed ghatao.

Q25: 140+120=260m, 78−60=18 → 260÷(18×5/18) = 52 sec Q26: 320+540=860m, 144−108=36 → 860÷10 = 86 sec
Q28: 70−34=36 → L₁+L₂ = 25×10 = 250 m
Q30: 3min=180s, 90−80=10 → x+230=500 → 270 m

PATTERN 14

Equal length trains → distance = 2L

Trigger: "two trains of EQUAL length, faster train overtakes/passes the slower one in t sec — length of EACH train?" — 2L likho.

Q27: 46−36=10 → 36 = 2L÷(10×5/18) → L = 50 m Q29: 60−42=18 → 40 = 2L÷5 → 2L=200 → L = 100 m
✓

PATTERN 15

Pehle bridge se SPEED nikalo, phir doosri train cross

Trigger: "train X, L m long, crosses a bridge in t min. How much time to cross another train Y running at ... in same direction?" — 2-step question.

Q31: (350+850)÷80s = 15 m/s; Y = 42km/h = 35/3 m/s
t = 600÷(15−35/3) = 180 sec = 3 min
✓

PATTERN 16

Same-dir time + Opp-dir time dono diye → speed ratio

Trigger: "same direction mein t₁ sec aur opposite direction mein t₂ sec mein cross karti hain" — x−y = D/t₁, x+y = D/t₂ banao.

Q32: (x−y)60 = (x+y)10 → 5x=7y → x:y = 7:5 Q34: x−y=600/20=30, x+y=600/12=50 → x=40, y=10 m/s → 144 & 36 km/h
Q35: x−y=120, x+y=600 → 720/2 : 480/2 = 3:2
✓

PATTERN 17

Equal-length trains, pole times diye → 2t₁t₂/(t₁∓t₂)

Trigger: "two trains of EQUAL length cross a pole in t₁ and t₂ sec — kitne time mein ek doosre ko cross karengi?" Same dir → minus, Opp dir → plus.

Q36: same dir → 2×5×7/(7−5) = 35 sec Q38: opp dir → 2×27×24/51 = 432/17 = 25.4 sec
Q37 (alag length): S₁=160/5=32, S₂=180/6=30 → t=340/2 = 170 sec
✓

PATTERN 18

Man ko t₁,t₂ + aapas mein T → speed ratio (alligation)

Trigger: "two trains cross a MAN standing on platform in t₁ & t₂ sec, aur opposite direction mein ek doosre ko T sec mein — ratio of speeds?"

Q39: 23 = (27S₁+17S₂)/(S₁+S₂) → 4S₁=3S₂... solve → 3:2 Q40: 18, 24 vs 20 → (24−20):(20−18) = 4:2 = 2:1
✓

PATTERN 19

Train ↔ chalta hua aadmi → t = L_train/(S_T ∓ S_M)

Q41: 6.5 = 130÷((x−12)×5/18) → x−12=72 → 84 km/h Q42: 252÷((125−17)×5/18) = 252/30 = 8.4 sec
Q44: 6s opp se train speed=131.4; phir 234÷(108×5/18) = 7.8 sec

PATTERN 23

Opp-dir aadmi se train SPEED nikalo → phir platform time

PATTERN 26

PATTERN 28

Fog / "dikhna band ho gaya" → distance = vis + L + vis

PATTERN 29

Engine fail → "kitna % speed badhaye time pe pahunchne ko"

Trigger: "after covering x% of distance engine fails, train delayed by m minutes — by what % should speed be increased to reach ON TIME?" — bacha hua time nikaalo, % = delay×100/naya time.

Q62: D=54×6=324; bacha time=4.8hr=288min; ab available=288−33=255
% = 33×100/255 = 12.94%
✓

PATTERN 30

Accident ke baad speed a/b ho gayi → "agar D km aage hota toh"

Trigger: "train met with accident after X km, moved at 5/6 (ya 4/5, 2/3) of speed, reached t₁ late. Had it occurred D km farther, only t₂ late" — dono ka time-difference us D km par lagao.

Q64: 18 km ka extra delay = 9 min... S = 18÷(36/60) = 30 km/h, D = 120 km Q65: 200 km par 10 min ka fark → S=200×60/20=600; total t=22/3 hr → D = 4400 km
Q63: 300 km par 1 hr fark, speed 5/6 → 50 km/h
Q66: 1hr baad accident, 50 km aage → 1hr20min late → D = 112.5 km
