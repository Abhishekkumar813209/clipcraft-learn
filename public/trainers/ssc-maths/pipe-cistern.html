PATTERN 01

Dono pipe ek saath → LCM/efficiency

Trigger: "A tank ko x ghante mein, B y ghante mein bhar sakta hai, dono ek saath khole jayein toh kitna time?"

Q1: A→18, B→24 → LCM 72, eff 4+3=7 → 72/7 = 10²⁄₇ hr Q2: A→4, B→6 → 12, eff 3+2=5 → 12/5 = 2²⁄₅ hr = 2 hr 24 min
✓

PATTERN 02

"50% tank x ghante mein" + answer minutes mein

Trigger: ek pipe ka time poora tank ka nahi, "50%/⅓ bhaag bharta hai" diya ho — pehle full-tank time nikalo, aur answer "(in minutes)" poocha ho toh ×60.

Q3: A 50% in 6hr → full 12hr; B→18 → LCM 36, eff 3+2=5
36/5 hr ×60 = 432 min

PATTERN 05

Pipes alag-alag time par khule → tanki kab bharegi?

Trigger: "A 6 a.m., B 8 a.m., C 10 a.m. par khola gaya — tanki kab bhar jayegi?" → equation: 2A + 2(A+B) + t(A+B+C) = T.W.

Q10: 15,30,40 → 120; 8,4,3. 2×8+2×12+15t=120 → t=16/3=5hr20min → 10:00+5:20 = 3:20 p.m. Q11: 30,40,60 → 120; 4,3,2. 1×4+2×7+9t=120 → t=34/3=11hr20min → 10:00 a.m.+11:20 = 9:20 p.m.
✓

PATTERN 06

Beech mein pipe badla → "tank kab EMPTY hoga?"

Trigger: "A aur C 9 a.m. par chalu, 2 ghante baad A band aur B chalu — tanki kab khali hogi?" → total work = 0 rakho.

Q12: A→1(10), B→2(5), C→5/4(−8) [T.W=10]
2(10−8) + t(5−8) = 0 → 4=3t → t=1hr20min → 11:00 + 1:20 = 12:20 p.m.

PATTERN 14
