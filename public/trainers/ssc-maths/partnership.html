PATTERN 01

Same time → Profit ratio = Investment ratio

Trigger: "dono ne ₹X aur ₹Y invest kiye, saal ke ant mein profit ka ratio / hissa kya hoga" — time ka zikr hi nahi.

Q1: 50000 : 40000 → 5 : 4 Q2: 36000:63000 → 4:7; profit 5500 → 1u=500 → ₹2000, ₹3500
✓

PATTERN 02

Alag-alag time → P = I × T

Trigger: "unhone ₹A, ₹B, ₹C invest kiye 3, 2, 4 saal/mahine ke liye" — total profit mein kisi ek ka share poocha jaaye.

Q3: 4000×3 : 6000×2 : 8000×4 = 3:3:8 → Y = 56000×3/14 = ₹12,000 Q7: 40000×5:45000×4:60000×3 = 10:9:9 → C% = 9/28×100 = 32%
✓

PATTERN 03

Profit diya hai → Investment nikaalo (P ÷ T)

Trigger: "P ko ₹1430, Q ko ₹1870, R ko ₹2420 mile — Q ne kitna invest kiya?" (total investment diya hai, time same).

Q4: P ratio 1430:1870:2420 = 13:17:22 (52 units) → 52000/52 × 17 = ₹17,000
✓

PATTERN 04

I aur P diya → Time nikaalo (T = P ÷ I)

Trigger: "investment ka ratio 14:15, profit ka ratio 2:5, A ne 3 mahine lagaye — B ne kitne mahine?"

Q5: T = 2/14 : 5/15 = 3:7; A=3 mahine → 1u=1 → B = 7 months Q6: I 5:4, P 6:5 → T = 6/5 : 5/4 = 24:25, farq 1u = 1 saal → Neha = 25 years
✓

PATTERN 05

Teen mein se do ratio diye → teesra ratio (cross-multiply)

Trigger: "I ka ratio a:b:c aur T ka ratio d:e:f diya — profit ratio batao" ya ulta "P aur I diya — T ka ratio batao".

Q8: I 3:4:8, T 2:3:5 → P = 6:12:40 = 3:6:20 Q9: I 3:4:8, P 2:3:5 → T = 2/3 : 3/4 : 5/8 = 16:18:15
Q12: T 7:8:14, P 8:7:5 (type) → I = P/T → 64:49:20
✓

PATTERN 06

Investment fraction/percent mein → LCM se units banao

Q17: 4/5 : 2/3 : 5/8 → LCM 120 → 96:80:75 → % compare karo (₹ share nikaal ke) Q17b: ratio se x ka hissa y se → 11/5 × 100% = 220%

PATTERN 07

"3A = 2B = 4C" type equation → ratio ulta karo

Q22: 3A=2B=4C → LCM 12 → A:B:C = 4:6:3 → share nikaalo (units × 1 unit) Q23: 2A=3B=4C → 6:4:3 → total profit se hissa = ₹6,000
