PATTERN 01

Teen mool identities — INCORRECT wala pakdo

Trigger: Q mein "select the INCORRECT formula" — options mein sec²θ+cos²θ jaisi mix-up line hoti hai.

Q1: sin²θ+cos²θ=1, sec²θ−tan²θ=1, cosec²θ−cot²θ=1 sahi → sec²θ+cos²θ=1 GALAT (answer)

PATTERN 02

cotθ+tanθ = secθ·cosecθ

Trigger: "Which of the following is equal to 1/tanθ + tanθ" — cot+tan dikhe.

Q2: cotθ+tanθ = (cos²+sin²)/sin·cos = 1/(sinθcosθ) = secθ·cosecθQ3: cosθ/sinθ + sinθ/cosθ = same → cosecθ·secθ

PATTERN 03

secA − cosA = sinA·tanA

PATTERN 04

PATTERN 05
